# Generative Zoning: A Study in Diffusion-Based Masterplanning

## Overview
This project explores dynamic zoning strategies through computational methods. By leveraging diffusion algorithms, it generates adaptive spatial patterns that respond to environmental and programmatic constraints, enabling data-driven masterplanning approaches for ecological restoration and site development.

## Core Concept
The system uses competitive diffusion as its primary mechanism. Multiple activators and inhibitors propagate through a spatial grid, competing for territory based on their proximity and influence strength. This creates organic, boundary-like zones that reflect the natural interplay of different spatial forces, similar to biological pattern formation processes.
